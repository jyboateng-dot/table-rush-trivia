# Live Rehearsal Checklist

Run this before the first real venue night.

## Device Setup

- 1 host laptop or tablet on the admin screen.
- 1 TV/browser device on the TV screen.
- 5 to 10 phones as table players.
- At least one phone on mobile data.
- At least one phone on venue Wi-Fi.

## Rehearsal Flow

1. Create a new event from the admin dashboard.
2. Confirm the secure admin URL contains `?key=`.
3. Open the TV link and scan the QR code with every phone.
4. Join 5 to 10 table names.
5. Vote across multiple categories.
6. Lock voting and confirm cache status becomes ready.
7. Start a question.
8. Submit answers from multiple phones.
9. Switch away from the game tab on one phone and confirm a focus flag appears.
10. Pause and resume the question.
11. Close and reveal the question.
12. Run at least 3 questions.
13. Disqualify and restore one test table.
14. Declare a winner.
15. Export results.
16. Archive the event.

## Pass Criteria

- QR opens the player page on all phones.
- Admin, TV, and player screens update within 2 seconds.
- Answers lock after submission.
- Timer closes the question without host intervention.
- Focus-loss cheating flag appears on admin.
- Results export opens successfully.
- Archived event still shows final winner.
